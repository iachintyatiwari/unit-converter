# Unit Converter

A lightweight and responsive Unit Converter web application built using **JavaScript** and **Bootstrap**. This project allows users to quickly and easily convert between various units of measurement.

## Features

- **Multiple Unit Categories**: Convert units for length, weight, temperature, volume, and more.
- **Real-Time Conversion**: Input values are converted instantly without the need to refresh the page.

## Technologies Used

- **HTML5**: Markup language for the structure of the application.
- **CSS3**: Used for custom styling and responsiveness.
- **JavaScript**: Core logic for unit conversions and interactive features.
- **Bootstrap**: For responsive layout and styling.

## Getting Started

### Prerequisites

To run this project, you need:
- A modern web browser (e.g., Chrome, Firefox, Edge).
- Basic knowledge of HTML and JavaScript if you want to customize the code.

### Installation

1. **Clone the Repository**:
    ```bash
    git clone https://github.com/iachintyatiwari/unit-converter
    ```

2. **Navigate to the Project Directory**:
    ```bash
    cd unit-converter
    ```

3. **Open the Project in a Browser**:
    Open `index.html` in any web browser to view the application.

## Usage

1. Open the application in your browser.
2. Select the unit category from the dropdown (e.g., Length, Weight, Temperature).
3. Input the value in the provided field.
4. View the converted value in real-time.
5. Switch between units or categories as needed.

## Customization

You can customize the application to add more unit categories or modify existing ones:

1. **Add Unit Categories**:
   - Update the dropdown menu in `dropdown.js`.
   - Add conversion logic in `dropdown.js`.

2. **Modify Styling**:
   - Update `styles.css` or override Bootstrap styles.
